# 📚 StudyHub Pro

StudyHub Pro is a browser-based productivity web app designed for students to manage tasks, focus sessions, and track progress in one place.

---

## 🚀 Features

- ✅ Task management (to-do list)
- ⏱️ Pomodoro timer for focused study sessions
- 📊 Analytics dashboard (weekly progress tracking)
- 🏆 Achievements & XP system
- 📝 Notes section
- 👤 Multi-user account system (browser-based)
- 💾 All data saved in localStorage per user

---

## 🧠 How it works

- Each user creates an account with email + PIN
- PIN is securely hashed using SHA-256
- All user data is stored locally in the browser
- Every user has isolated data (tasks, sessions, XP, etc.)
- No backend or server is required

---

## 📁 Tech Stack

- HTML
- CSS
- JavaScript
- localStorage (for data persistence)
